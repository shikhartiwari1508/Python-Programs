## ⚙️ Installation and Setup

### 1. Install Python

Download Python from the official website:

[Download Python](https://www.python.org/downloads/)

Verify the installation:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/shikhartiwari1508/Python-Programs.git
```

### 3. Navigate to the Project

```bash
cd Python-Programs
```

### 4. Install Required Libraries

For programs that use data science or machine learning libraries, install the relevant packages:

```bash
python -m pip install numpy pandas matplotlib seaborn scipy scikit-learn
```

Some individual projects may require additional packages. For example, a QR code generator may require a QR code library, and a weather checker may require an HTTP client or API configuration.

## ▶️ Running the Programs

Run any Python script from the terminal:

```bash
python calculator.py
```

For a machine learning script, navigate to the correct folder and run its filename:

```bash
python linear_regression.py
```

If you are using Windows, you can also use:

```bash
py calculator.py
```

**Important:** Run each program separately. Some scripts expect keyboard input, local datasets, particular packages, or internet access.
